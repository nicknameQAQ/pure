自己用的本地 Markdown 查看与编辑工具，首个公开版本。

- 新建文件直接显示在当前目录，自动编号，F2 重命名。
- 侧栏可拖动调整大小，记住宽度，双击恢复默认。
- 源码和打印视图按需加载，长文统计使用后台线程，目录查询共用缓存。
- 保留查找替换、焦点模式、打字机模式、标题大纲、公式、Mermaid、草稿恢复和 PDF 导出。

推荐下载 `pure-0.3.0-win-x64.zip`，解压后运行 `pure.exe`；单 EXE 每次启动需要先解包。

`pure-0.3.0-source.zip` 为完整项目源码，`SHA256SUMS.txt` 用于校验下载文件。性能实测和使用限制见仓库文档。
